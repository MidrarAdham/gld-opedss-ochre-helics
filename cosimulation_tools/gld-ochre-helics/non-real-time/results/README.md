# Introduction:
This directory is dedicated for co-simulation results. This folder does **NOT** contain the actual results; it contains 
manifest files. 

## Manifest files:

Manifest files are simply csv files that are generated by other repository files. To avoid memory issues, the manifest files comprises simulation files directories and building IDs. 

All data used to run co-simulation are located in '''/mnt/datasets/''' directory

## How to get the data:
In [this repo](git@github.com:PortlandStatePowerLab/midrar-ochre-resstock2025-compat-2025.git), there are scripts that are designed to extract the data for a specific type of simulation. Review the README file within that repo before running data analysis on this repo.
